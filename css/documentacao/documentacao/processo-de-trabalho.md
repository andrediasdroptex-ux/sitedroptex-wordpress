# DROPTEX - Processo de Trabalho

## Regra Principal

Antes de qualquer alteração:

Analisar toda a estrutura existente.

Nunca recriar funcionalidades já existentes.

Nunca apagar funcionalidades sem validação.

Sempre reaproveitar a estrutura atual.

# Processo de Alteração

1. Analisar situação atual.

2. Documentar alteração proposta.

3. Criar backup lógico via GitHub.

4. Executar alteração.

5. Testar.

6. Registrar resultado.

7. Atualizar documentação.
