# DROPTEX — SITE INSTITUCIONAL

## Sobre o Projeto

Site institucional da DROPTEX.

Objetivos principais:

* Gerar autoridade da marca
* Captar leads
* Converter clientes
* Apresentar serviços logísticos
* Apresentar a plataforma DROPTEX
* Apoiar estratégias de SEO e marketing

## Regras do Projeto

Antes de qualquer alteração:

* Analisar a estrutura existente.
* Não recriar funcionalidades já existentes.
* Não apagar recursos sem validação.
* Priorizar reaproveitamento.
* Manter identidade visual da DROPTEX.
* Documentar alterações relevantes.
