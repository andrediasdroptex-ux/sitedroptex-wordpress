# PROMPT PADRÃO CODEX — DROPTEX

## Contexto do Projeto

A DROPTEX é uma operação de logística, intermediação comercial e educação.

O site tem como objetivos:

* Gerar autoridade.
* Captar leads.
* Converter clientes.
* Apresentar serviços logísticos.
* Apresentar a plataforma DROPTEX.
* Vender produtos.
* Vender mentorias e treinamentos.

## Antes de qualquer alteração

Analisar integralmente a estrutura existente.

Verificar:

* Tema
* Plugins
* Páginas
* CSS
* Formulários
* SEO
* Responsividade
* Performance
* Fluxo de navegação
* Objetivo comercial da página

Antes de sugerir alterações, identificar:

* O problema atual.
* A causa provável.
* O impacto esperado.
* Os arquivos envolvidos.

---

## Regras Obrigatórias

### NÃO FAZER

* Não recriar funcionalidades existentes.
* Não apagar recursos sem validação.
* Não instalar plugins sem necessidade.
* Não alterar identidade visual sem justificativa.
* Não criar funcionalidades duplicadas.
* Não modificar fluxos estáveis sem explicar os impactos.
* Não propor alterações apenas por preferência pessoal.

### DEVE FAZER

* Priorizar reaproveitamento.
* Manter consistência visual.
* Priorizar simplicidade.
* Documentar alterações relevantes.
* Explicar riscos antes da implementação.
* Considerar impacto em SEO e conversão.

---

## Critérios de Avaliação

Toda sugestão deve considerar:

### UX

* Facilidade de navegação.
* Clareza visual.
* Redução de cliques.
* Melhor experiência mobile.

### SEO

* Estrutura semântica.
* Hierarquia de títulos.
* Links internos.
* Performance.

### Conversão

* Captação de leads.
* Autoridade.
* CTA.
* Confiança.

### Performance

* Velocidade.
* Peso de arquivos.
* Plugins desnecessários.
* CSS redundante.

### Mobile

* Responsividade.
* Legibilidade.
* Espaçamentos.
* Botões e formulários.

---

## Forma de Resposta

Antes de sugerir alterações, explicar:

1. O que será alterado.
2. Por que será alterado.
3. Benefícios esperados.
4. Possíveis riscos.
5. Arquivos envolvidos.

Sempre priorizar melhorias com maior impacto e menor risco.
